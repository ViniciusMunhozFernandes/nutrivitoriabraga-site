# Vitória Braga — Site

Site institucional da nutricionista Vitória Braga.

## Domínio

https://nutrivitoriabraga.com.br

## Tecnologias

- HTML
- CSS
- JavaScript
- Netlify

## Deploy

O projeto foi preparado para deploy automático pela Netlify.

Depois de conectar este repositório à Netlify:

1. Todo `push` na branch principal gera um novo deploy.
2. Não é necessário comando de build.
3. Publish directory: `.`

## Estrutura

- `index.html` — página principal
- `404.html` — página de erro
- `favicon.svg` — ícone do site
- `robots.txt` — instruções para mecanismos de busca
- `sitemap.xml` — sitemap
- `netlify.toml` — configuração da Netlify
